# 💯 Library Management Admin Dashboard
Using Nuxt.js with PrimeVue module to create easy to use admin dashboard.

---

## 🧐 Features
* **🔒 Authentication:**
  * Clean login and registration system secured with authentication middleware.
* **📂 Full CRUD Operations:**
  * Complete management panels for **Authors**, **Categories**, **Books**, and **Logs**.
* **🎨 Utility-First Styling:** 
  * Clean, fully responsive layouts powered by TailwindCSS.

---

## 🛠️ Tech Stack
* **Framework:** Nuxt.js (Vue 3)
* **UI Library:** PrimeVue
* **Styling:** TailwindCSS
* **State Management/Data Fetching:** Build-in State Management/ Axios

---

## 🚀 Getting Started

Follow these simple steps to get a local copy up and running.

### Prerequisites
List any software or packages the user needs installed beforehand.
```bash
npm install npm@latest -g
```
## ➡️ Installation & Setup

#### 1. Clone this repository:
```bash
git clone [git@github.com:KaungMon/library-management-client.git](git@github.com:KaungMon/library-management-client.git)
```

#### 2. Navigate into the directory:
```bash
cd library-management-client
```

#### 3. Install the dependencies:
```bash
npm install
```
#### 4. Configure Environment Variables:
  Create a .env file in the root directory to point the frontend to your backend API:

  ```bash
  BASE_URL=http://localhost:8000
  API_BASE_URL=http://localhost:8000/api
  ```

#### 5. Run the development server:
```bash
npm run dev
```
